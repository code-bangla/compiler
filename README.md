# কোড.বাংলা

কোড.বাংলা একটি আধুনিক, টাইপ-নিরাপদ, উচ্চ-গতিসম্পন্ন প্রোগ্রামিং ভাষা যা সম্পূর্ণ বাংলায় লেখা যায়। এটি দিয়ে গুরুতর সফটওয়্যার তৈরি করা যায়—ওয়েব সার্ভার, ডেস্কটপ অ্যাপ, কমান্ড-লাইন টুল, ডেটা টুলস ইত্যাদি।

## মূল বৈশিষ্ট্য

- সম্পূর্ণ বাংলা: কীওয়ার্ড, কমান্ড, এরর মেসেজ, ডকুমেন্টেশন—সব বাংলায়।

- মেমোরি-নিরাপদ: রাস্টের উপর ভিত্তি করে তৈরি; মেমোরি লিক, বাফার ওভারফ্লো ইত্যাদি ঝুঁকি কম।

- দুই মোড:
  - ইন্টারপ্রেটেড: দ্রুত ডেভেলপমেন্ট, কোনো লিঙ্কার লাগে না।

  - কম্পাইলড: বিশুদ্ধ মেশিন কোডে পরিণত হয়; কোনো ভার্চুয়াল মেশিন বা রানটাইম ছাড়াই চলে।

- নেটিভ বাইনারি: উইন্ডোজ, লিনাক্স, ম্যাকওএস-এ সরাসরি চালানো যায়।

- আইডিই ও এআই রেডি: ভবিষ্যতে এলএসপি (LSP) সাপোর্ট, ফরম্যাটার, ডিবাগার।

## নমুনা কোড

```কোড.বাংলা
চলক বয়স = ১৬

ধ্রুবক নাম = "অনন্যা"

দেখাও(`আমার নাম ${নাম}, আমার বয়স ${বয়স}`)

যদি (বয়স >= ১৮) {
  প্রাপ্তবয়স্ক = হ্যা;
} নতুবা {
  প্রাপ্তবয়স্ক = না;
}

```

## বাস্তবায়ন পরিকল্পনা

- [ ] ধাপ ০: প্রস্তুতি
  - [x] রাস্ট ওয়ার্কস্পেস তৈরি।
  - [ ] প্রয়োজনীয় ক্রেট যোগ করা: clap, cranelift-\* বা inkwell, unicode-segmentation ইত্যাদি।
  - [ ] ইউনিকোড হ্যান্ডলিং নিশ্চিত করা (NFC নরমালাইজেশন, আইডেন্টিফায়ার সিকিউরিটি)।

- [ ] ধাপ ১: ফ্রন্টএন্ড
  - [ ] ১. লেক্সার
    - [ ] ইউটিএফ-৮ ফাইল পড়া।
    - [ ] বাংলা কীওয়ার্ড শনাক্ত করা (যেমন: যদি, অন্যথা, ফাংশন, রিটার্ন, ভেরিয়েবল)।
    - [ ] আইডেন্টিফায়ার, লিটারাল, অপারেটর টোকেনে ভাগ করা।
  - [ ] ২. পার্সার
    - [ ] টোকেন থেকে AST তৈরি।
    - [ ] সিনট্যাক্স এরর হ্যান্ডলিং।
  - [ ] ৩. টাইপ চেকার
    - [ ] নাম রেজোলিউশন (ভেরিয়েবল, ফাংশন)।
    - [ ] টাইপ মিল যাচাই।
    - [ ] বাংলা + ইংরেজি এরর মেসেজ (প্রাথমিকভাবে বাংলা প্রাধান্য)।

- [ ] ধাপ ২: মধ্যবর্তী উপস্থাপনা (IR)
  - [ ] একটি সাধারণ, টাইপযুক্ত IR ডিজাইন:
    - [ ] লোড, স্টোর, কল, রিটার্ন, জাম্প, শর্তসাপেক্ষ জাম্প, গাণিতিক অপারেশন ইত্যাদি।
    - [ ] AST থেকে IR-এ রূপান্তর।

- [ ] ধাপ ৩: ইন্টারপ্রেটার
  - [ ] IR-এর উপর সরাসরি ভার্চুয়াল মেশিন:
    - [ ] কল স্ট্যাক, লোকাল ভেরিয়েবল, হিপ।
    - [ ] Value টাইপ: সংখ্যা, বুল, টেক্সট, অ্যারে, ক্লোজার ইত্যাদি।
    - [ ] বাংলা চালাও কমান্ড:
      - [ ] পার্স → টাইপ চেক → IR → ইন্টারপ্রেট।

- [ ] ধাপ ৪: কম্পাইলার (নেটিভ)
  - [ ] কোডজেন:
    - [ ] IR থেকে Cranelift/LLVM IR-এ রূপান্তর।
    - [ ] ফাংশন, ব্লক, ভেরিয়েবল ম্যাপিং।
    - [ ] অবজেক্ট ফাইল তৈরি:
      - [ ] মেশিন কোড জেনারেট করে .o/.obj ফাইল তৈরি।
  - [ ] লিঙ্কার:
    - [ ] রানটাইম + সিস্টেম লাইব্রেরির সাথে লিঙ্ক।
    - [ ] উইন্ডোজে link.exe/lld, লিনাক্সে ld/lld/clang।
    - [ ] বাংলা তৈরি করো কমান্ড:
      - [ ] পার্স → টাইপ চেক → IR → কোডজেন → লিঙ্ক → নেটিভ এক্সিকিউটেবল।

- [ ] ধাপ ৫: স্ট্যান্ডার্ড লাইব্রেরি
  - [ ] লেখা: স্ট্রিং অপারেশন, ইউনিকোড ইউটিলিটি।
  - [ ] সংগ্রহ: অ্যারে, তালিকা, ম্যাপ, সেট।
  - [ ] ফাইল: ফাইল পড়া/লেখা, পথ হ্যান্ডলিং।
  - [ ] ইনপুট_আউটপুট: লেখো, পড়ো ইত্যাদি।
  - [ ] গণিত: মৌলিক গাণিতিক ফাংশন।
  - [ ] নেটওয়ার্ক, এসিকিউএল, পোস্টগ্রেস, জেসন, সিএসভি ইত্যাদি।

- [ ] ধাপ ৬: কমান্ড-লাইন ইন্টারফেস
  - [ ] clap ব্যবহার করে বাংলা কমান্ড তৈরি।
  - [ ] সাবকমান্ড: চালাও, তৈরি করো, পরীক্ষা করো, সাজাও, সংস্করণ, সাহায্য।
  - [ ] সব হেল্প টেক্সট ও এরর মেসেজ বাংলায়।

- [ ] ধাপ ৭: টেস্টিং ও সিআই
  - [ ] ইউনিট টেস্ট: লেক্সার, পার্সার, টাইপ চেকার।
  - [ ] ইন্টিগ্রেশন টেস্ট: ছোট .কোড প্রোগ্রাম কম্পাইল ও রান।
  - [ ] কনফরম্যান্স টেস্ট: প্রতিটি ভাষা বৈশিষ্ট্যের জন্য প্রত্যাশিত আচরণ।
  - [ ] গিটহাব অ্যাকশন্স বা সমমানের সিআই।
  - [ ] উইন্ডোজ ও লিনাক্সে বিল্ড।
  - [ ] টেস্ট রান।
  - [ ] স্যাম্পল প্রোগ্রাম বিল্ড।

- [ ] ধাপ ৮: আইডিই ও এআই সাপোর্ট
  - [ ] এলএসপি (LSP):
    - [ ] ডায়াগনস্টিকস (ত্রুটি/সতর্কতা)।

  - [ ] ফরম্যাটার:
    - [ ] বাংলা সাজাও কমান্ড।
  - [ ] ডকুমেন্টেশন টুল:
    - [ ] কোড কমেন্ট থেকে ডক জেনারেট।

  - [ ] প্যাকেজ রেজিস্ট্রি (অনলাইন বা স্থানীয়)।
